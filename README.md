# 📊 매크로 지표 대시보드

매일 주요 매크로 지표를 자동으로 기록하고, 중요도순으로 한눈에 보는 대시보드입니다.
서버도, 복잡한 설치도 없습니다. **Python 파일 하나**로 동작합니다.

데이터 출처: **Stooq**(지수·환율·원자재) · **Coinbase**(암호화폐) · **FRED**(VIX·미국채금리·M2·RRP·경제지표) · **CNN**(공포·탐욕 지수).

## 동작 방식

```
python3 record.py  실행  →  ① 지표 수집
                            ② data/날짜.json 으로 그날 기록 저장
                            ③ dashboard.html 다시 그림
```

- **dashboard.html** 을 더블클릭하면 (서버 없이) 대시보드가 열립니다.
- `data/` 폴더에 하루치씩 파일이 쌓여서, 1주·1개월 추세가 자동으로 표시됩니다.

## 지표 구성 (성격별 묶음)

| 묶음 | 지표 |
|---|---|
| **시장 심리** | VIX 공포지수, CNN 공포·탐욕 지수, 달러인덱스, 장단기 금리차(10Y-2Y), M2 통화량 |
| **주요 자산** | S&P 500, 나스닥, 코스피, 금, WTI 유가, 달러/원, 비트코인, 이더리움 |
| **미국 매크로 경제지표** | 미국 10년물·2년물 금리, CPI, 실업률, 기준금리, 역레포(RRP), Fed Balance |
| **미국 섹터** | S&P500 SPDR 11섹터(기술·금융·헬스케어·임의/필수소비재·에너지·산업재·소재·유틸리티·리츠·커뮤니케이션) — 그날 상승률 순 히트맵 |

> 지표를 더하거나 빼고 싶으면 `record.py` 위쪽의 `INDICATORS` 목록만 고치면 됩니다.
> (각 지표의 `group` 값 1·2·3이 위 세 묶음에 해당합니다.)

## 처음 한 번만 — FRED 키 설정

주가·환율·원자재·코인은 **키 없이 바로** 동작합니다.
**VIX·미국 10년물 금리·3순위 경제지표(CPI·실업률 등)**는 무료 FRED 키가 필요합니다.
(이미 설정해 두셨습니다 ✅)

1. https://fredaccount.stlouisfed.org/apikeys 에서 가입 후 키 발급 (무료, 1분)
2. 이 폴더에서 `.env` 파일을 만들고 키를 넣기:
   ```
   FRED_API_KEY=발급받은키
   ```
   (`.env.example` 을 복사해서 쓰면 됩니다.)
